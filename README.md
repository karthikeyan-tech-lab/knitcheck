# KnitCheck — Program Feasibility Assistant

A lightweight open-source browser tool for textile sampling and knitting teams.

## Features
- Feeder/course feasibility check
- Sample machine-day estimate
- YD/stripe and special-sample review flags
- Technical callout summary
- No framework, npm, backend, database, or API key
- GitHub Pages ready

## Important
This is a planning assistant, not a replacement for machine trials or technical approval. Its rules are intentionally simple and transparent so textile professionals can improve them.
